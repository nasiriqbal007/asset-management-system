# Employee Asset Management System

A web-based system for managing company assets and employees. Supports asset requests, approvals, allocations, returns, activity logging, authentication, and reporting.

# Backend

TechStack : Typescript, Node, PostgresSQL, Express

# Prerequisites

- Node.js LTS version
- PostgreSQL 18+
- Express

# Setup Instructions

1. Clone repository
2. Install dependencies: `npm install`
3. Create `.env` file
4. Add environment variables
5. Run database schema setup
6. Start server: `npm run dev`

Server runs on `http://localhost:3000`
